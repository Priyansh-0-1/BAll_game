# BAll_game
🎮 Ball Game
A simple and interactive ball game built using HTML5 Canvas and JavaScript. The game challenges players to control a bouncing ball, avoid obstacles, and score points — designed for fun and fast-paced gameplay in the browser.

🚀 Features
🟠 Smooth ball physics and collision detection

🎯 Point scoring system based on survival or target hits

💥 Dynamic obstacles and increasing difficulty

🎨 Simple, clean UI using HTML/CSS

🔁 Responsive design for desktop and mobile

🛠️ Tech Stack
HTML5 Canvas

JavaScript (Vanilla)

CSS3
